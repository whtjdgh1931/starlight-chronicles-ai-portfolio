# 실행 확인과 검증 범위

## 데모에서 확인하는 동작

1. Unity Hub에서 `UnityDemo`를 추가합니다. Unity **6000.4.8f1**로 `Assets/Scenes/PortfolioDemo.unity`를 열고 Play를 누릅니다.
2. **Start boss attack**을 눌러 분홍색 예고가 플레이어 위치를 추적하는 모습을 봅니다.
3. 예고가 금색으로 바뀌면 경로가 확정됩니다. **Lane** 버튼으로 이동해 확정된 경로를 피할 수 있습니다.

이 데모의 확인 범위는 예고, 경로 확정, 회피입니다. 전체 게임은 [Windows 빌드](../README.md#게임-실행)에서 시연합니다.
