# Project Maple Legacy GDD v4.1 개정 부록

- 최초 개정일: 2026-07-24
- 진행 상태 갱신일: 2026-07-31
- 대상 문서: PML-GDD-004, GDD v4 Detailed
- 개정 원칙: 본 부록의 규칙이 기존 문서와 충돌하면 본 부록을 우선한다.

## 1. 레벨과 경험치

- 레벨업에 필요한 경험치를 초과하여 획득한 경우 초과 경험치의 90%만 다음 레벨 경험치로 이월한다.
- 나머지 10%는 레벨업 이월 페널티로 소멸한다.
- 한 번의 경험치 획득으로 여러 레벨이 상승하면 각 레벨업 단계마다 동일한 90% 이월 규칙을 적용한다.
- 레벨업 시 MaxHP, MaxMP, 공격력, 방어력은 직업과 무관한 고정 증가량을 적용한다. 증가량은 PlayerStat의 단일 설정 지점에서 관리한다.
- 레벨업 직후 HP와 MP는 증가된 최대치까지 회복한다.
- 경험치 UI는 페널티 적용 이후의 실제 현재 경험치와 다음 레벨 요구 경험치를 표시한다.

## 2. 필드 아이템 획득 규칙

- 기본 획득 방식은 플레이어의 수동 획득 입력이다.
- 획득 범위 안에 여러 드롭이 겹쳐 있으면 거리순으로 검사하고, 실제로 수령 가능한 가장 가까운 드롭 하나를 획득한다.
- 특정 드롭의 대상 인벤토리 탭이 만석이어도 골드, 합산 가능한 아이템, 다른 탭의 아이템 획득을 막지 않는다.
- 인벤토리가 받을 수 없는 드롭은 필드에 유지한다.
- 수동 획득과 자석 획득은 동일한 IPickupReceiver 수령 계약을 사용한다.
- 한 드롭에 여러 획득 요청이 발생해도 보상은 한 번만 지급한다.

## 3. 장비 드래그 앤 드롭 UX

- 인벤토리에서 장비 슬롯으로 드롭하면 호환되는 부위에 장착한다.
- 장비 슬롯에서 인벤토리로 드롭하면 장착을 해제한다. 인벤토리에 받을 공간이 없으면 장착 상태를 유지한다.
- 장비 슬롯 사이 이동은 대상 부위가 호환될 때만 허용한다.
- 인벤토리 또는 장비 슬롯에서 강화 슬롯으로 드롭하면 소유 위치를 변경하지 않고 해당 InventoryItemData 인스턴스를 강화 대상으로 등록한다.
- 강화 슬롯에서 인벤토리나 장비 슬롯으로 드래그하는 동작은 소유권 이동으로 처리하지 않는다.
- 잘못된 위치, 호환되지 않는 부위, 만석, 파괴된 장비 등으로 실패하면 원래 데이터와 UI 상태를 유지한다.
- UI는 드래그 중 임시 표현만 변경하며, 실제 데이터 트랜잭션 성공 후 전체 슬롯을 다시 렌더링한다.
- 장착 중인 아이템의 강화 결과는 즉시 장비 스탯과 외형에 반영한다. 파괴되면 자동 장착 해제하고 외형을 제거한다.
- 장비는 플레이어 레벨이 아이템의 요구 레벨 이상일 때만 장착할 수 있다.
- 요구 레벨을 충족하지 못하면 인벤토리 위치, 기존 장비와 스탯을 변경하지 않는다.
- 더블클릭과 드래그 장착은 동일한 장착 가능 여부 검사를 사용한다.

## 4. 직업, 주스탯과 전투 계산

- 플레이어 직업은 `PlayerClass`로 구분한다.
- 직업별 주스탯은 기존 `StatType` 중 하나를 반환하는 단일 매핑에서 관리한다.
- 직업과 주스탯의 기본 매핑은 다음과 같다.

| PlayerClass | MainStatType |
| --- | --- |
| Warrior | Str |
| Archer | Dex |
| Magician | Int |

- `PlayerStatData.BaseStat`은 현재 직업의 주스탯 초기값으로 적용한다.
- 장비의 `AddStat`과 강화의 `BaseBonusStat`은 장착한 플레이어의 현재 주스탯에 적용한다.
- 현재 직업과 무관한 `Str`, `Dex`, `Int`는 삭제하지 않고 후속 직업 구현을 위해 유지한다.
- 기본 유효 공격력은 `Atk + (MainStat × MainStatCoefficient)`로 계산한다.
- 초기 `MainStatCoefficient`는 `1.0`이며, 이후 밸런스 조정을 위해 전투 또는 직업 설정 데이터에서 관리한다.
- 스킬 한 타의 기본 피해는 `유효 공격력 × SkillDamageMultiplier`로 계산한다.
- 다단히트는 각 타격에 정의된 `SkillDamageMultiplier`를 같은 계산 경계로 적용한다.
- 방어력, 치명타, 속성, 랜덤 피해 편차는 전사 기본 스킬 검증 이후 별도 규칙으로 추가한다.

## 5. 지상 판정과 점프

- 지상 상태는 점프 횟수가 아니라 플레이어 콜라이더 아래의 실제 지면 접촉으로 판단한다.
- 발판 끝에서 걸어 떨어진 경우 즉시 공중 상태로 전환한다.
- 접지한 순간 점프 횟수를 초기화한다.
- 상승 중, 밑점프 중이거나 지면 충돌을 무시하는 동안에는 접지로 판정하지 않는다.
- 지상 판정은 이동, 점프 가능 여부와 애니메이션이 공유하는 단일 상태를 사용한다.

## 6. 아이템 툴팁

- 인벤토리와 장비 슬롯은 같은 아이템 툴팁 표현을 사용한다.
- 툴팁은 이름, 종류, 설명, 요구 레벨, 기본 스탯, 강화 단계와 강화 추가 스탯을 표시한다.
- 장비는 현재 플레이어 기준 장착 가능 여부를 표시한다.
- 요구 레벨을 충족하지 못한 항목은 시각적으로 구분하되 툴팁이 장착 로직을 직접 변경하지 않는다.
- 툴팁은 시스템에서 계산된 결과를 표시하며 스탯과 장착 가능 여부를 별도로 재계산하지 않는다.

## 7. 몬스터 처치 생명주기

- 몬스터 처치와 풀 반환은 서로 다른 시점으로 구분한다.
- `OnKilled`는 HP가 0이 되어 처치가 확정된 시점의 알림이다.
- 경험치 지급과 드롭 생성은 `OnKilled` 시점을 사용한다.
- `OnReturnedToPool`은 사망 연출이 끝나고 몬스터가 풀로 반환되는 시점의 알림이다.
- 몬스터 스포너의 활성 몬스터 목록 정리는 `OnReturnedToPool` 시점을 사용한다.
- 한 번의 활성화 주기에서 각 알림은 최대 한 번만 발생한다.

## 8. 자석 스킬과 펫 획득

- 자석 획득 공통 기능은 MagnetPickupScanner가 담당한다.
- 스캐너는 탐색 중심, 반경, 비행 목표 Transform, IPickupReceiver, 동시 처리 한도를 입력받는다.
- 아이템이 날아갈 위치와 실제 보상을 수령하는 대상을 분리한다.
- 자석 스킬은 플레이어를 비행 목표로 사용하고, 스킬 범위와 지속시간 또는 단발 스캔 규칙을 적용한다.
- 펫은 펫 Transform을 비행 목표로 사용하되 보상은 플레이어의 IPickupReceiver가 수령한다.
- 자석 이동 중 인벤토리가 만석이 되면 아이템을 소멸시키지 않고 필드 상태로 복구한다.
- 이미 자석 이동 중인 드롭은 다른 수동 입력, 스킬, 펫이 중복 예약할 수 없다.

## 9. MVP 범위

- M1에서는 수동 획득 안정화와 MagnetPickupScanner, 자석 이동, 중복 방지, 만석 복구까지 구현한다.
- M3에서는 고정 레벨업 성장, 장비 드래그 앤 드롭, 장착 아이템 강화 연결, 직업별 주스탯 기반 전투 계산과 전사 기본 스킬을 구현한다.
- M4에서는 버전된 저장, 원자 저장과 백업 복구를 완료하고 아이템 툴팁과 주요 UI를 연결한다.
- 자석 스킬은 전사 기본 스킬과 전투 계산 검증 이후 구현한다.
- 펫의 추적, 자동 획득, 장착 상태와 저장은 M8 또는 MVP 이후 콘텐츠로 분리한다.
